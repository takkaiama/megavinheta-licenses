# MegaVinheta Licenses

Repositório público de licenças assinadas do MegaVinheta Studio.

- Aplicativo: MegaVinheta Studio v4.0.0
- Pasta de licenças: `licenses/`
- Os arquivos de licença são criados/atualizados pelo painel Admin.
- Os clientes fazem somente leitura HTTPS.
- O nome do arquivo é o SHA-256 derivado do login normalizado.
- Não coloque neste repositório token GitHub, chave privada, senha administrativa ou backup do painel Admin.

A chave `public-key.pem` é pública e serve apenas para conferência da assinatura. A chave privada correspondente deve permanecer somente com o proprietário.
